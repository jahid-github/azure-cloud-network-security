
# Azure Enterprise Cloud Networking & Security Lab

## Project Overview
A hands-on learning project to design, deploy,
secure, automate, and monitor an enterprise
network infrastructure using Microsoft Azure.

## Business Scenario
A fictional Finnish company is modernizing
its IT infrastructure by using Azure cloud
networking and security services.

## Learning Goals
- Learn Microsoft Azure fundamentals
- Understand cloud networking
- Deploy and configure virtual machines
- Implement network security
- Manage identities and access
- Automate infrastructure deployment
- Monitor and troubleshoot cloud resources

## Technologies
Microsoft Azure, Windows, Linux, GitHub,
PowerShell, Azure CLI, Terraform

## Current Progress
Phase 0 - Environment preparation in progress

## Project Type
Educational and portfolio lab
